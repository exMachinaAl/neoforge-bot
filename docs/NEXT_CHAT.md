## Chat tanpa akses folder

> Proyek Arcadia/neoforge-bot. Saya memberikan ZIP/source terbaru beserta commit baseline. Baca README.md, AGENTS.md, docs/HANDOFF.md dan TODO.md. Untuk tugas [isi tujuan], kembalikan ZIP berisi file final yang berubah dengan path relatif dari root proyek, manifest perubahan, petunjuk penerapan dan status uji. Jangan membuat fix.js, skrip penambal, atau menebak file yang belum tersedia. Jangan sertakan .env, data pribadi/runtime, server atau node_modules.

Berlaku untuk Claude, ChatGPT dan Gemini dalam mode chat. Jika source belum tersedia, minta arsip/source; jangan menyatakan telah mengedit folder pemilik. Jangan meminta API key dalam chat.
